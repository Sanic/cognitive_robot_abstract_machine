    Locks use the model root axes, independent of view/crop yaw. Unchecked axes are locked exactly. A plane may constrain height while leaving sideways movement ambiguous.
    
        
    
        
    Select a body to check box eligibility.
    Each present geometry role must be a box with compatible face directions. Box axes follow the actual surfaces and are labeled in the preview; they are recovered geometric axes, not source URDF axes. The same affine mapping resizes both roles; existing role-specific margins scale with the body.
    
          
    
            
            
            
          
    Dimension axes are independent of crop yaw. Keeping the center requires returns on both opposing faces. Fixing a face requires returns on the moving opposite face; the fixed face is an assumption you declare.
    
        
    
        
    
        
        
    Translation uses robust surface correspondences. Box dimensions use median face positions and declared anchors. Both check exact triangle-distance improvement on the same initially associated records; this is an in-sample fit, not independent accuracy.

    How to read these results
    Scan → model measures unsigned distance to the nearest triangle and assigns the record to that body. It does not establish semantic correspondence.
    Model → scan samples each body surface by area and checks for nearby evaluated scan records inside the same crop. The global percentage is weighted by represented area. Per-body percentages describe that body's sampled area.
    No nearby evidence is unknown support: occlusion, sparse sampling, transparent or dark material, and absent geometry can all cause it. This is not visibility, free-space occupancy, confidence or proof of an error. Changing either sample budget can change the result.
